🛡

EDGAR-Compliant Crawling

Token-bucket rate limiter capped at SEC's 10 req/s policy. Descriptive User-Agent on every request. Exponential backoff on 429/5xx. Honors If-Modified-Since on index files.

♻

Idempotent Ingestion

Accession-number-based deduplication. Amendments tracked, never silently overwritten. Failed parses persisted to a dead-letter table with full stack traces for replay.

🧩

Multi-Format Parsing

XML for Form 4 / 13F-HR, XBRL via arelle for fundamentals, HTML via selectolax for 10-K sections. Section detection uses header-text + heuristic positioning.

🧠

Semantic Risk Search

Risk-factor text chunked with 50-token overlap, embedded by BAAI/bge-small-en-v1.5, stored in pgvector with HNSW. Cosine similarity returns top-K in under 100ms.

🤖

Local LLM Diff Engine

Year-over-year risk-factor changes summarized by Llama 3.1 8B running on Ollama. Aggressive caching means the Russell 1000 annual diffs run overnight on a laptop.

📊

BI + REST in One

Metabase dashboards for analyst-style exploration. FastAPI with auto-generated OpenAPI for programmatic access. Both backed by the same Postgres warehouse.
